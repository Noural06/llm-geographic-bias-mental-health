# Does Where You Live Shape What You Get?

Geographic variation, measurement validation, and crisis-information reliability in LLM mental-health guidance.

## Study at a glance

This dissertation audits 1,120 responses generated by seven LLMs for eight fixed mental-health scenarios across 20 cities. Only the stated city and country vary across geographic conditions. The study asks whether location is associated with:

1. actionability by World Bank income category;
2. localisation by documented crisis-service availability; and
3. religious or spiritual framing by WHO region.

A separate exploratory audit examines verified, visibly suspicious, and unresolved crisis-contact information. It does **not** estimate a fabrication rate.

## Evidence status

| Analysis | Status | Reason |
|---|---|---|
| RQ1: actionability | Exploratory | Frozen actionability failed fresh hold-out validation ($\kappa_w=0.462$). The income pattern is sensitive to crisis-contact inclusion and service availability. |
| RQ2: localisation | Exploratory | Surface localisation failed specificity (0.038) on the fresh hold-out. Verified localisation is an unvalidated sensitivity measure. |
| RQ3: religious framing | Retained with caution | Separately assessed, but the reference labels come from one coder and WHO region remains geographically confounded. |
| Crisis-contact audit | Exploratory safety signal | Suspicious digit patterns are lower-bound flags. Unmatched contacts remain unresolved unless source evidence establishes correctness. |

Statistical significance and leave-one-model-out stability do not repair measurement failure. The rule-based pipeline outperformed the experimental Qwen coder on a common 40-response subset, but neither method was validated for confirmatory RQ1/RQ2 use.

## Quick start

Use Python 3.11 or 3.12 from the repository root:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python src/check_repository.py
jupyter notebook src/Geographic_variation_analysis_FINAL_SUBMISSION.ipynb
```

The notebook writes a clean rerun beneath `results/reproduced/`. Committed summary outputs and validation workbooks remain in `data/processed/` and `results/` so the reported results can be inspected without rerunning the full notebook. The large response-level coded dataset is regenerated by the notebook and is intentionally not duplicated in the repository.

To reproduce the fresh hold-out metrics independently:

```bash
python src/analyse_holdout.py
```

See [REPRODUCIBILITY.md](REPRODUCIBILITY.md) for the execution order, expected outputs, data roles, and known limitations.

## Remaining limitations

- No independent second coder was available.
- The initial repeat-coding exercise changed the coding instrument between occasions; a frozen-codebook repeat remains future work.
- The geographic sample contains only 20 cities and does not support global or causal claims.
- All prompts are in English and only one generation was collected per design cell.
- H3 does not fully separate WHO region from income, culture, or infrastructure.

No real patient records, clinical data, or real-user crisis disclosures are included.
