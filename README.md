## Project overview

This repository contains the code, configuration files, figures, dissertation materials, and supplementary outputs for an MSc Data Science dissertation that investigates whether geographic context affects the mental health guidance generated by large language models (LLMs).

The project uses a controlled experimental design: the mental health scenario text is held constant, while only the city and country in the prompt are varied. This allows the analysis to isolate geographic context as the main independent variable.

---

## Dissertation title

**Does Where You Are Shape What You Get?**  
**Geographic Variation in Large Language Model Responses to Mental Health Queries**

---

## Research questions

1. Do large language models generate systematically different mental health responses across geographic contexts?
2. Do large language models provide less actionable mental health guidance in lower-resource settings compared with higher-resource settings?
3. What implicit cultural and contextual assumptions are reflected in geographically contextualised mental health responses generated by large language models?

---

## Dataset

The final dataset contains **1,120 AI-generated responses**.

| Dimension | Value |
|---|---:|
| Cities | 20 |
| Mental health scenarios | 8 |
| Language models | 7 |
| Total responses | 1,120 |
| World Bank income categories | 4 |
| WHO regions | 6 |

Each response corresponds to one unique combination of:

```text
city × scenario × language model
```

The prompt format was:

```text
I live in [City], [Country]. [Mental health scenario]
```

---

## Models evaluated

The study evaluated seven contemporary LLMs:

- Google Gemma 4 26B A4B Instruct
- GPT-OSS 120B
- Mistral Small 2506
- Meta Llama 3.3 70B Instruct
- Qwen 3 32B
- Meta Llama 4 Scout 17B-16E Instruct
- NVIDIA Nemotron-3 Super 120B A12B

## Reproducibility

The repository is intended to support the reproducibility of the dissertation analysis. The complete workflow is organised around:

1. generating or loading the experimental matrix;
2. Collecting model responses through APIs;
3. preprocessing responses;
4. performing BERTopic topic modelling;
5. extracting linguistic features;
6. running statistical tests;
7. Generating figures and supplementary visualisations.

API keys are **not** included in this repository. They should be stored locally as environment variables or secure notebook secrets.

---

## Ethical note

This project analyses AI-generated text only. It does not involve human participants, personal data, or clinical interventions. The analysis does not assess the clinical effectiveness of AI-generated mental health guidance. It should not be interpreted as a recommendation to use LLMs as substitutes for qualified mental health professionals.
