# Model provenance

No trained weights or serialized task-specific models are included.

The experimental Modern NLP coder used the pretrained `Qwen/Qwen2.5-1.5B-Instruct` model through prompt-based generative classification. It was not fine-tuned, and embeddings were not extracted to train a downstream classifier. Download the model from its original provider if reproducing that development experiment, and record the exact model revision used.

The seven response-generating LLMs are documented in the dissertation and analysis notebook. They are distinct from the Qwen automated coder.
