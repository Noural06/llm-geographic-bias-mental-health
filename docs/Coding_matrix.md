# Geographic Variation in Large Language Model Responses to Mental Health Queries.

## Purpose

The pilot dataset consists of 36 responses generated by three large language models (GPT-4o, Gemini, and Claude) in response to six mental health prompts across two geographic locations (London and Lagos).

The coding matrix was developed from the preliminary codebook and used to identify the presence or absence of themes in each response.

## Coding Approach

Each response was reviewed manually.

Themes were coded as:

* 1 = Theme present
* 0 = Theme absent

Responses could be assigned multiple themes.


## Dataset Structure

Variables recorded:

* Response ID
* Prompt
* Model
* Location
* Theme 1 (Institutional Healthcare Navigation)
* Theme 2 (Support Under Resource Constraints)
* Theme 3 (Behavioural Self-Management)
* Theme 4 (Localised Resource Referral)
* Theme 5 (Professional Mental Health Referral)
* Theme 6 (Community Integration and Belonging)
* Theme 7 (Financial Security and Economic Resilience)
* Theme 8 (Caregiver Burden and Emotional Exhaustion)
* Theme 9 (Formal vs Informal Support Systems)
* Theme 10 (Integrated Physical and Mental Health Care)

## Purpose of Analysis

The coding matrix supports comparison across:

* Models (GPT-4o, Gemini, Claude)
* Locations (London, Lagos)
* Mental health scenarios

The matrix will be used during the formal thematic analysis stage to identify recurring patterns and differences in model responses.
