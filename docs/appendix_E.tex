\section*{E.3 Reproducibility Note}

The analysis notebook is designed to be run top to bottom from the source data files. It requires standard Python scientific computing packages (pandas, numpy, scipy, scikit-learn, statsmodels, matplotlib). Random seeds are fixed where randomness is used (e.g. the Jeffreys-interval Monte Carlo propagation in the H3 validation scoring), so that re-running the pipeline reproduces the exact figures reported in this dissertation.

\section*{E.4 Data Availability and Ethics}

No real user data, patient data, or personally identifiable information is contained in the repository. All mental health scenarios are synthetic constructions (Appendix A); all response data was generated by querying LLM APIs with these synthetic prompts, not collected from real users. Human validation labels were applied to model-generated text, not to real crisis disclosures.

\section{Helpline Verification: Full Classification by Category}
\label{app:helpline_full}

\subsection{Classification Categories}

Four categories were applied to all 466 unique (country, number) pairs extracted from crisis-context response segments:

\begin{itemize}
    \item \textbf{Verified real:} number matched to a documented crisis service in a primary source (Wikipedia's List of Suicide Crisis Lines, WHO, IASP, Befrienders Worldwide, or an official ministry website). \textit{n = 45 (9.7\%)}
    \item \textbf{General emergency:} standard national emergency number (112, 911, 999, 000, 119) not specific to mental health. \textit{n = 39 (8.4\%)}
    \item \textbf{Visibly suspicious:} number matches a 555-block, repeated-digit ($\geq 4$), or sequential-digit ($\geq 5$) pattern. \textit{n = 75 (16.1\%)}
    \item \textbf{Unverifiable:} no match found in primary sources \emph{and} no synthetic pattern detected. Could be a real service not captured in the reference sources, or a plausible-looking fabricated number. \textit{n = 307 (65.9\%)}
\end{itemize}

\textbf{Terminology note:} ``Visibly suspicious'' and ``fabricated'' are not synonyms. Visibly suspicious denotes a pattern match; fabrication is not asserted beyond what the pattern evidence and the absence of any documented service jointly support.
